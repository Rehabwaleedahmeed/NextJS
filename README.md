# Lab1

Next.js pages-router demo with:

- Static site generation via `getStaticProps`
- Dynamic routes via `getStaticPaths` and `getStaticProps`
- Navbar hidden on error routes
- Brand filtering, search, and sorting for DummyJSON products
- Deferred search updates with React `useTransition` and `useDeferredValue`

## Run

```bash
npm install
npm run dev
```
